# Клиентский калькулятор «Искра»

Первая версия клиентского мини-сайта для понятного расчёта печатной продукции.

## Сейчас
- адаптивный интерфейс;
- пошаговый сценарий: продукт → размер → дизайн → результат;
- категории: баннер, наклейки, плёнка, таблички, буквы и формы;
- фирменный стеклянный персонаж без рук и ног;
- предварительный расчёт.

Цены в первой версии — прототип. Перед публикацией нужно перенести точные правила из внутреннего калькулятора.
